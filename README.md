# Travel Expense Calculator (C++)

This is a console-based C++ program that calculates and compares business travel expenses with allowable reimbursement limits.

## 📌 Features
- Input number of travel days
- Enter departure and arrival times
- Calculate:
  - Round-trip airfare
  - Car rental cost
  - Mileage expenses
  - Parking fees (daily limits applied)
  - Taxi fees (daily limits applied)
  - Hotel expenses (daily limits applied)
  - Meal expenses (based on time rules)
  - Conference fees
- Outputs:
  - Total actual expenses
  - Total allowable expenses
  - Excess amount to reimburse or savings

```bash
g++ TravelExpenses.cpp -o program
